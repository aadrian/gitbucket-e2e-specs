Use Cases: notifications plugin
===============================

What the bundled `notifications` plugin adds. IDs `notifications:UC-<type>-NNN`; ID scheme and format in `../../docs/e2e-plan.md`.

- notifications:UC-D-001 Developer watches a repository
  - Repository page → watch button (Watching, Not watching, Ignoring). The choice is saved without a page reload.
- notifications:UC-U-002 User turns email notifications off
  - Account settings → Notifications → Disable → Save.
