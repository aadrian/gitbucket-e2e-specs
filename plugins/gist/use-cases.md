Use Cases: gist plugin
======================

What the bundled `gist` plugin adds. IDs `gist:UC-<type>-NNN`; ID scheme and format in `../../docs/e2e-plan.md`.

- gist:UC-U-001 User creates a snippet
  - Snippets → description, file name and content in the editor, Public / Secret / Private → Create.
- gist:UC-U-002 User comments on a snippet
  - Snippet page, comment box → Comment.
- gist:UC-U-003 User deletes their snippet
  - Snippet page → Delete, confirm dialog.
